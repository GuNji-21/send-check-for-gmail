# プライバシーポリシー

対象：Chrome 拡張機能「Send Check for Gmail」（以下「本拡張機能」）

最終更新日：2026年11月24日

## 1. 取り扱う情報

本拡張機能は、Gmail で送信前の確認を行うために、作成中のメールの次の情報を読み取ります。

- 送信元のメールアドレス
- 宛先（To / Cc / Bcc）のメールアドレスと表示名
- 件名・本文
- 添付ファイルの名前などの情報

このほか、次の情報を取り扱います。

- 利用者が設定画面で登録した内容（社内ドメイン、要注意・確認省略の宛先、添付キーワード、警告のオン・オフなど）
- 連絡先の記録（利用者が設定画面で有効にした場合のみ。初期設定は無効）
  - 対象：利用者がメールを送信した社外の宛先（To / Cc / Bcc）。あわせて、社外の相手に送ったメールで Cc に入れた人（社内の人を含む）
  - 項目：メールアドレス、表示名、ドメイン、To・Cc に入れた回数、最後に送った日、「どの相手へのメールで、誰を Cc に入れたか」とその回数
  - 利用者が台帳の画面で入力した項目、または CSV から取り込んだ項目：氏名、会社名、会社の別名、部署、役職、電話番号、携帯番号
  - 取得元：利用者が作成したメールの宛先欄、利用者自身の入力、利用者が選んだ CSV ファイル
  - 届いたメールからの補完（利用者が設定画面で「届いたメールからも連絡先を補う」を有効にした場合のみ。初期設定は無効）：Gmail の画面に開いたメールの送信元（アドレス、表示名）、宛先に入っている人（アドレス、表示名）、署名（会社名、部署、役職、電話番号、携帯番号）を読み取り、すでに記録がある相手の情報を補います。記録に無い相手から届いたメール（メールマガジンなど）は記録しません。本文そのものは保存しません
  - 利用目的：初めて送るドメインであることの警告、いつも Cc に入れている人が入っていないことの警告、本文の宛名・会社名と宛先の照合、確認の画面での会社名の表示、会社名での検索
  - 有効にする前に送ったメールと、社内だけに送ったメールは記録しません

## 2. 情報の処理と外部送信

- メールの内容・宛先・連絡先情報は、利用者のブラウザ内でのみ処理し、外部に送信しません。
- 本拡張機能は、開発者のサーバーを含む外部のサーバーと通信しません。
- Gmail API は使用しません。
- AI による誤字・脱字チェック（利用者が有効にした場合のみ）は、Chrome に内蔵された AI（Gemini Nano）を使い、利用者の端末内で処理します。メールの内容を外部の AI サービスに送信することはありません。

## 3. 情報の保存

- 保存するデータは、利用者の端末内にのみ保存します。設定は chrome.storage に、連絡先の記録は IndexedDB に保存します。
- 件名・本文・添付ファイルの情報は保存しません。確認の間だけ読み取ります。届いたメールの本文も保存しません（署名から読み取った会社名・部署・役職・電話番号だけを、連絡先の記録に保存します）。
- 連絡先の記録は、最後に送った日から一定の期間（初期値は1年。設定画面で6か月〜5年から選べます）が過ぎると、自動的に削除します。
- 開発者が利用者のデータにアクセスすることはできません。

## 4. 第三者への提供・利用目的の制限

- 開発者が利用者のデータを取得・販売することはありません。
- 利用者のデータを広告に利用することはありません。

## 5. データの削除

- 利用者は、本拡張機能の設定画面から、登録した内容を削除できます。
- 連絡先の記録は、設定画面の「連絡先の記録をすべて削除」から、いつでもすべて削除できます。台帳の画面では、1件ずつ削除できます。
- 連絡先の記録は、利用者の操作で CSV ファイルに書き出せます。書き出したファイルは、利用者の端末に保存されるだけで、本拡張機能が外部に送信することはありません。
- 本拡張機能をアンインストールした場合も、本拡張機能が保存したデータは削除されます。
