## 1. 取り扱う情報

本拡張機能は、Gmail で送信前の確認を行うために、作成中のメールの次の情報を読み取ります。

- 宛先（To / Cc / Bcc）のメールアドレスと表示名
- 件名・本文
- 添付ファイルの名前などの情報
- 利用者が設定画面で登録した内容（社内ドメイン、要注意・確認省略の宛先など）
- 連絡先情報（会社名・氏名・メールアドレス等。将来のバージョンで、利用者が送信したことのある相手のみを対象に蓄積する予定）

## 2. 情報の処理と外部送信

- メールの内容・宛先・連絡先情報は、利用者のブラウザ内でのみ処理し、外部に送信しません。
- 本拡張機能は、開発者のサーバーを含む外部のサーバーと通信しません。
- Gmail API は使用しません。

## 3. 情報の保存

- 保存するデータは、利用者の端末内（chrome.storage、IndexedDB）にのみ保存します。
- 開発者が利用者のデータにアクセスすることはできません。

## 4. 第三者への提供・利用目的の制限

- 開発者が利用者のデータを取得・販売することはありません。
- 利用者のデータを広告に利用することはありません。

## 5. データの削除

- 利用者は、本拡張機能の設定画面から保存データを削除できます。
- 本拡張機能をアンインストールした場合も、本拡張機能が保存したデータは削除されます。

## 6. ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。
