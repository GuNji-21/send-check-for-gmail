## 1. 取り扱う情報

本拡張機能は、Gmail で送信前の確認を行うために、作成中のメールの次の情報を読み取ります。

- 送信元のメールアドレス
- 宛先（To / Cc / Bcc）のメールアドレスと表示名
- 件名・本文
- 添付ファイルの名前などの情報

このほか、次の情報を取り扱います。

- 利用者が設定画面で登録した内容（社内ドメイン、要注意・確認省略の宛先、添付キーワード、警告レベルなど）
- 連絡先情報（将来のバージョンで蓄積する予定）
  - 対象：利用者がメールを送信した相手（To / Cc）、および届いたメールの Cc に入っていた人のうち、登録済みの会社のドメインと一致する人
  - 項目：メールアドレス、氏名、会社名、部署・役職、電話番号、To / Cc に入った回数、最終やりとり日
  - 取得元：利用者が作成したメールの宛先・宛名、および上記の相手から届いたメールの送信元・Cc・署名（Gmail の画面に表示された内容から読み取ります）

## 2. 情報の処理と外部送信

- メールの内容・宛先・連絡先情報は、利用者のブラウザ内でのみ処理し、外部に送信しません。
- 本拡張機能は、開発者のサーバーを含む外部のサーバーと通信しません。
- Gmail API は使用しません。

## 3. 情報の保存

- 保存するデータは、利用者の端末内（chrome.storage、IndexedDB）にのみ保存します。
- 開発者が利用者のデータにアクセスすることはできません。

## 4. 第三者への提供・利用目的の制限

- 開発者が利用者のデータを取得・販売することはありません。
- 利用者のデータを広告に利用することはありません。

## 5. データの削除

- 利用者は、本拡張機能の設定画面から保存データを削除できます。
- 本拡張機能をアンインストールした場合も、本拡張機能が保存したデータは削除されます。

## 6. ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。
