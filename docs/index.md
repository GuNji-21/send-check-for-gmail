# Gmail 送信前チェック（仮） / Gmail Send Guard

Gmail の送信前に宛先・本文・添付を確認し、誤送信を防ぐ Chrome 拡張機能です。

A Chrome extension that reviews recipients, body and attachments before sending in Gmail to prevent mis-sends.
